# Use chair-directed deliberation

OpenAgentCouncil uses a neutral Chair to select relevant Council Members, gather isolated Positions in parallel and then run bounded open Rounds. Each completed Position is shown to the user immediately but remains hidden from members still forming their own Positions; workspace writes require a user-approved Assignment and are limited to one Council Member at a time. This preserves independent perspectives, prevents uncontrolled agent loops and concurrent edits, and keeps the user in control.
