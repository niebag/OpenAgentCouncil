# Bound member capabilities by role and Assignment

Council Members can read the current repository while forming Positions, but only members with the explicit `web` capability may use web search and fetch tools. An approved Assignment grants one member repository-wide writes for its declared goal while keeping network access disabled; its expected file list describes intent rather than acting as a brittle allowlist. OpenAgentCouncil shows the resulting diff so deviations remain visible without building a cross-CLI file policy engine.
